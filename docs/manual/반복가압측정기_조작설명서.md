## 1. 안전 수칙

안전한 작업 환경에서 작업 효율을 높이고 상해 사고를 예방하기 위해 아래 안전 수칙을 준수하십시오. 본 설명서 지침을 지키면 장비를 오랫동안 최적의 성능으로 사용할 수 있습니다.

### 1.1 경고 표시
| 구분 | 의미 |
|---|---|
| **[감전 주의]** | 제어반·전원부 내부에 고전압. 자격자 외 개방 금지. |
| **[비상정지]** | 위험 시 즉시 비상정지(EMO) 버튼을 누르십시오. |
| **[협착 주의]** | 가압 실린더·가동부에 손을 넣지 마십시오. |
| **[접근 금지]** | 운전 중 라이트 커튼 감지 영역에 신체를 넣지 마십시오. |

### 1.2 안전 장치
- **비상정지(EMO)**: 누르는 동안 솔레노이드 전원을 차단합니다. 밸브(5/3 클로즈드센터)가 중립으로 가 실린더가 **그 자리에서 정지**합니다.
- **라이트 커튼**: 감지 영역에 물체/신체가 들어오면 구동을 차단합니다.
- 두 장치는 모두 **`구동 허가` 신호**로 제어부에도 전달되어, 화면 상단이 **`구동 차단`** 으로 바뀌고 **안전 정지(SAFETY STOP)** 상태가 됩니다. 이때 모든 액추에이터와 진공 출력이 강제로 꺼집니다.

### 1.3 안전 정지 및 복귀
1. 위험 요인(비상정지 눌림, 라이트 커튼 감지 등)을 제거합니다.
2. 화면 상단 **`구동 허가`** 표시가 초록으로 돌아온 것을 확인합니다.
3. 안전 정지 화면에서 **`안전 복귀`** 를 누릅니다. (부저는 안전 복귀를 누를 때까지 울립니다. 시끄러우면 **`부저 정지`** 로 잠시 끌 수 있습니다.)
4. **복귀 후 진공은 자동으로 켜지지 않습니다.** 필요 시 다시 켜십시오.

### 1.4 일반 주의사항
- 실린더 하강·가압 중 손·공구를 넣지 마십시오(협착 위험).
- 정전 시 밸브는 스프링 센터로 중립(정지)이 됩니다. 잔압에 주의하십시오.
- 공압이 연결되지 않았거나 규정 압력 미만이면 정상 동작하지 않습니다.

## 5. 주요 특징
- 터치스크린 HMI(한글).
- 안전: 라이트 커튼 + 비상정지 + `구동 허가` 인터록, 안전 정지/복귀.

- **레시피 3슬롯**.
- 진공 흡착(옵션, 수동 전용).

## 8. 조작 방법

### 8.1 화면 구성
- **상단바**: 모드(자동/수동) · 상태(대기/운전/안전정지 등) · 시계.
- **상태 스트립**(램프): `구동 허가` · `실린더`(상승/하강/미확인) · `진공` · `하중 정상` · `통신 정상`.
- **하단 네비게이션**: 운전 · 조건설정 · 시스템상태 · 로그 · 도움말.
- 관리자 화면(유지보수)은 우측 상단 **설정(톱니바퀴) 버튼 + 암호**로 진입합니다.

### 8.2 운전 화면 (메인) [그림]
- **왼쪽(현재 동작)**: 현재 상태·자동 단계·Dwell 남은시간, 우상단에 **반복 횟수**(대형). 하단 조작 버튼 — `안전 복귀` · `알람 해제` · `횟수 초기화` · `하중 영점`.
- **오른쪽(현재 하중)**: 실시간 하중(대형 kgf) · 현재 최대 · 운전 최대 · 하중 상한 · 실시간 트렌드 그래프 · 진행률. 하단에 진공 — `진공 명령` · `진공 확인` · **`진공 켜기/끄기`**.

### 8.3 자동 운전
1. 제어반 셀렉터를 **AUTO** 위치로 돌립니다(상단바가 `자동`).
2. **조건설정**에서 반복 횟수·유지시간·하중 상한 등을 확인/적용합니다(§8.5).
3. 시료를 올리고(필요 시 진공 켜기), **Auto Start** 를 누릅니다.
4. 자동 사이클이 진행됩니다:
   **하강 → 가압 유지(Down Dwell) → 상승 → 유지(Up Dwell) → 카운트 +1**, 설정 횟수만큼 반복.
5. 설정 횟수를 채우면 **교체 위치(상단 센서)로 이동한 뒤 정지**합니다(시료 교체 편의). 화면은 `운전 완료`.
6. 다시 시작하려면 **Auto Start** 를 누릅니다(횟수 초기화 후 반복).
- **중지**: **Auto Stop** — 사이클을 중단하고 자동 대기로 돌아갑니다.
- **하강 위치센서 미도달**: 시료 크기에 따라 하강 센서에 닿지 않을 수 있으며, 이는 **오류가 아닙니다**(이동시간 경과 시 정상 진행). 과가압은 하중 상한이 보호합니다.
- **하강 하중 도달 사용**(옵션): 하강 중 로드셀이 기준값 이상이면 도달로 보고 가압 유지로 넘어갑니다(§8.5).

### 8.4 수동 운전
1. 셀렉터를 **MANUAL** 위치로 돌립니다(상단바가 `수동`).
2. **Manual Up / Manual Down** — 누르는 동안 실린더가 이동하고, **위치 센서에 닿으면 정지**합니다.
   - 하강은 시료 크기에 따라 하강 센서에 닿지 않을 수 있으며, 이는 정상입니다(버튼을 누르는 동안 계속 가압).
- **교체 위치 이동**: 실린더를 상단 센서까지 올려 정지시키는 기능. 시료 교체 시 사용합니다.

### 8.5 조건 설정
| 항목 | 단위 | 설명 |
|---|---|---|
| 목표 반복 횟수 | 회 | 자동 반복 횟수 |
| 하강 유지시간 | 초 | 하강 후 가압 유지 시간 |
| 상승 유지시간 | 초 | 상승 후 유지 시간 |
| 하강 제한시간 | 초 | 하강 이동시간(센서 미도달 시 이 시간 후 진행) |
| 상승 제한시간 | 초 | 상승 이동시간(짧은 스트로크 가능) |
| 하강 하중 도달 사용 | 체크 | 로드셀 기준으로 하강 도달 판정 |
| 하강 도달 하중 | kgf | 위 기준 하중 |
| 하중 상한 | kgf | 초과 시 과가압 보호(정지) |
| 진공 확인 제한시간 | 초 | 진공 ON 후 확인 신호 대기 |
| 그래프 표시 구간 | 초 | 트렌드 그래프 시간 |
| 화면 밝기 | % | 디스플레이 밝기 |

- 값을 누르면 숫자 키패드로 편집합니다. **편집만으로는 반영되지 않습니다** — 반드시 **`적용`** 을 눌러야 운전에 반영·저장됩니다(편집 중에는 "수정됨(적용 필요)" 표시).
- `기본값`(초기값 불러오기) · `취소`(되돌리기) · `저장`(레시피 슬롯에 저장).
- **모든 설정 변경은 대기 상태에서만 가능합니다.**

### 8.6 레시피
- **저장**: `저장` → 슬롯(1~3) 선택 → 현재 편집값을 저장.
- **불러오기**: `레시피 1/2/3` → 확인 → 즉시 적용("레시피 N 적용").

### 8.7 시스템 상태 [그림]
- **제어기 및 통신**: 프로그램·실행시간·CPU 온도·저장공간·폴링·로드셀 원신호·진공 확인, **모듈 연결 램프**(입출력1/2/아날로그).
- **입출력 1/2**: DI/DO 상태(켜짐=초록).
- **아날로그**: A0~A3 = 전류(mA, A0=로드셀), A4~A7 = 전압(V).

### 8.8 로그
- **운전 기록** · **알람** · **이벤트** · **하중 트렌드** 탭.
- **알람 탭**: 안전정지 · 오류정지 · 밸브 인터록 · 하중 상한 초과 · 통신 오류 · 진공 경고 등(상태전환 등 일반 이벤트와 분리).

### 8.9 진공 조작
- 진공은 **수동 전용**이며 자동 사이클과 완전히 독립입니다(자동 시작/완료/정지가 진공을 바꾸지 않음).
- 운전 화면에서 `진공 켜기/끄기`. `진공 확인` 은 흡착 확인 센서 표시입니다.

### 8.10 유지보수 화면 (관리자) [그림]
- 설정(톱니바퀴) 버튼 + 암호로 진입.
- **I/O 단위 시험**: 램프·부저 등 출력을 개별 확인(밸브/진공은 안전상 제외).
- **로드셀 캘리브레이션**:
  1. **영점**: 무부하 상태에서 `하중 영점` → 현재 값을 0으로.
  2. **스팬**: 기준 하중을 올린 상태에서 스팬 보정 → 기준값에 맞춤.

### 8.11 도움말 / 매뉴얼
- 빠른 사용법과 하드웨어 조정(공압) 요약을 화면에서 확인할 수 있습니다(스크롤).

## 9. 하드웨어 조정

### 9.1 이동 속도 — 스피드 컨트롤러(스피드콘)
- 실린더 밸브의 배기 스피드 컨트롤러로 이동 속도를 조절합니다.
- **위쪽 = 상승 속도**, **아래쪽 = 하강 속도**. 조이면 느려지고 풀면 빨라집니다.
- 조절 후 잠금 너트로 고정하십시오.

### 9.2 최대 압력 — 레귤레이터(우측)
- 우측 레귤레이터로 가압 **최대 압력**을 설정합니다.
- 대략 **1 MPa 당 약 100 kgf** 로 환산해 목표 하중에 맞춰 미세 조절합니다.
  - 예) 300 kgf 목표 → 약 3 MPa.
- **하중 상한(조건설정)보다 낮게** 두는 것이 안전합니다.

### 9.3 로드셀 영점/스팬
- 유지보수 화면에서 무부하 `하중 영점`, 기준 하중으로 스팬 보정(§8.10).

## 10. 알람 및 안전 정지

- **알람 목록**(원인·조치):

| 알람 | 원인 | 조치 |
|---|---|---|

| 수동 동시 입력 | Up/Down 동시 | 한쪽만 |
| 상승 위치 미도달 | 교체 이동 시간 초과 | 배선/센서·시간 확인 |

## 11. 청소 및 유지보수
- **일상**: 운전 전 수 회 공회전하여 이상 소음·진동 확인. 로드셀/실린더 상태 확인.
- **월간**: 가이드·도금부 윤활, 공압 필터·레귤레이터 드레인/점검, 배선·커넥터 조임 확인.
- **노이즈 대책**(정비 참고): 솔레노이드 코일 플라이백 다이오드/스너버, **USB 라인 페라이트 코어**, 통신선과 동력선 분리. (본 장비는 USB 라인 페라이트로 재열거를 억제함.)

## 12. 고장 처리
| 고장 | 원인 | 조치 |
|---|---|---|
| 화면 무표시·미동작 | 전원 미연결/차단기 트립 | 전원·차단기 확인, 플러그 재연결 |
| 상단 `구동 차단` 지속 | 비상정지 눌림/라이트 커튼 감지/구동 허가 회로 | 원인 제거 후 `안전 복귀` |
| 통신 끊김·재접속 잦음 | 솔레노이드 스위칭 노이즈로 USB 재열거 | USB 페라이트, 솔 스너버, 통신선 분리 |
| 실린더가 멈추지 않음 | 밸브/배선(예: DO COM에 +24V 오배선) | 배선 점검, 싱크 COM=0V 확인, 5/3 중립 확인 |
| 하강 시 위치 오류 발생 | (구버전) 센서 미도달을 오류 처리 | 현행은 정상 처리 — 하중 상한으로 보호 |
| 하중 값 이상 | 로드셀 영점/스팬·배선 | 영점·스팬 재보정, 4–20 mA 배선 확인 |
| 자동 시작 안 됨 | 셀렉터 MANUAL/구동 차단/알람 | AUTO 확인, 알람 해제, 구동 허가 확인 |
| 진공 확인 안 뜸 | 진공 센서 배선/극성 | 배관·센서 확인(진공은 운전과 독립) |
