## 1. 안전 수칙 (Safety)
- 일반 안전 수칙(서문): 본 설명서를 숙지 후 작업, 자격자 설치 등.
- 경고 픽토그램: ⚡감전 주의 / 🛑비상정지(EMO) / ✋가동부(실린더)·협착 주의 / 🚷운전 중 접근 금지.
- **안전 장치 설명**:
  - 비상정지(EMO): 누르면 솔레노이드 전원 차단 → 실린더 정지(5/3 클로즈드센터 중립).
  - **라이트 커튼**: 감지 시 구동 차단(안전 정지).
  - 두 장치 모두 `구동 허가(SOL_ENABLE)` 신호로 제어부에도 반영 → SAFETY_STOP.
- 복귀: 원인 제거 → 상단 `구동 허가` 확인 → HMI `안전 복귀`.
- `[작성예정]` 잔압/낙하 주의, 정전 시 거동(스프링센터 → 중립 정지).

- 용도: 공압 실린더로 시료에 **반복 가압**을 가하고 **로드셀로 하중을 측정**하는 시험 장비.
- 특징 요약(1문단): 터치스크린 제어, 자동 반복 사이클, 하중 상한 보호, 진공 흡착(수동, 옵션), 레시피.

## 5. 주요 특징 (Main Features)
- 터치스크린 HMI(라이트 테마, 한글).
- 안전: 라이트 커튼 + 비상정지 + `구동 허가` 인터록, 안전 정지/복귀.
- **로드셀 하중 측정**: 실시간 하중, 현재/운전 최대, 하중 상한 초과 보호.
- **자동 반복 가압**: 하강→가압유지→상승→유지→카운트, 설정 횟수 반복. 완료 후 **교체 위치(상단)로 이동해 정지**.
- **하강 하중 도달 판정**(옵션): 위치센서 없이 로드셀 기준값으로 도달 판정.
- **레시피 3슬롯** 저장/불러오기.
- **진공 흡착**(옵션, 수동 전용 — 자동 사이클과 완전 독립).

## 7. 설치 준비 (Installation)
1. 개봉·수평 설치·청소.
2. 공압 연결(≥0.4 MPa) — 연결 시 실린더 거동 확인.

## 8. 조작 방법 (Operation)
### 8.1 터치스크린 개요
- 부팅 화면(초기 점검) → 메인. 상단바(모드/상태/시계), 상태 스트립(구동허가·실린더·진공·하중·통신), 하단 네비(운전·조건설정·시스템상태·로그·도움말).
### 8.2 운전 화면 (Main) [그림]
- 좌: 현재 동작/단계/dwell 남은시간/반복 횟수, 조작 버튼(안전복귀·알람해제·횟수초기화·하중영점).
- 우: 현재 하중(대형)·현재/운전 최대·하중 상한·트렌드·진행률·진공(명령/확인/토글).
### 8.3 자동 운전 (Auto)
- 셀렉터를 AUTO → 조건 확인 → **Auto Start**. 사이클: 하강→가압유지→상승→유지→카운트, 반복.
- 완료 시 **교체 위치(상단 센서)로 이동 후 정지**. 재시작은 Auto Start.
- 중지: Auto Stop.
### 8.4 수동 운전 (Manual)
- 셀렉터 MANUAL → Manual Up/Down(누르는 동안 이동, 위치센서 도달 시 정지). 하강은 시료로 센서 미도달 가능(정상).
- **교체 위치 이동**: 상단 센서까지 상승 후 정지.
### 8.5 조건 설정 (Settings) [그림]
- 항목: 목표 반복 횟수, 하강/상승 유지시간, 하강/상승 제한시간, 하강 하중 도달 사용·기준값, 하중 상한, 진공 확인 제한시간, 그래프 구간, 화면 밝기.
- **편집 → `적용`을 눌러야 반영**(편집만으론 미반영, "수정됨(적용 필요)").
### 8.6 레시피 (Recipe)
- `저장`으로 슬롯(1~3)에 현재 편집값 저장. `레시피 N`으로 불러와 즉시 적용.
### 8.7 시스템 상태 (System Status) [그림]
- 제어기/통신 요약, 모듈 연결 램프, 입출력1/2(DI/DO), 아날로그(A0~3 전류/A4~7 전압), 진공 출력 허가.
### 8.8 로그 (Logs)
- 탭: 운전 기록 · 알람 · 이벤트 · 하중 트렌드. 알람 탭 = 안전정지/오류/블로킹 알람/진공 경고.
### 8.9 진공 조작 (Vacuum)
- **수동 전용**, 자동 사이클과 독립. 진공 켜기/끄기, 진공 확인 표시.
### 8.10 유지보수 화면 (Maintenance, 관리자) [그림]
- ⚙ + 암호. IO 단위 시험, 진공/파기 시험(hold-to-run), **로드셀 영점/스팬 캘리브레이션**.
### 8.11 도움말 / 매뉴얼
- 빠른 사용법, 하드웨어 조정(공압) 요약.

## 9. 하드웨어 조정 (Hardware Adjustment)
- **속도 조절(스피드 컨트롤러)**: 위쪽=상승 속도, 아래쪽=하강 속도. 조이면 느려짐, 조절 후 고정.
- **최대 압력(우측 레귤레이터)**: 대략 **1 MPa 당 약 100 kgf** 로 환산해 목표 하중에 맞춰 미세 조절(예: 300 kgf → 약 3 MPa). 하중 상한보다 낮게.
- **로드셀 영점/스팬**: 무부하에서 `하중 영점`, 기준 하중으로 스팬 보정(유지보수 화면).

## 10. 알람 및 안전 정지 (Alarms & Safety)
- 안전 정지: 발생 조건/부저(안전 복귀까지 지속·부저 정지 버튼)/복귀 절차.
- 알람 목록(원인·조치): 밸브 인터록, 수동 동시입력, 상승 위치 미도달(교체), 하중 상한 초과, 통신 오류(USB/RS-485), 진공 경고류.

## 11. 청소 및 유지보수 (Cleaning & Maintenance)
- 일상: 운전 전 수 회 공회전(이상 소음 확인), 로드셀/실린더 이상 유무.
- 월간: 가이드/도금부 윤활, 공압 필터·레귤레이터 점검, 배선/커넥터 점검.
- 노이즈 대책(솔레노이드 플라이백/스너버, USB 페라이트) `[정비 참고]`.
