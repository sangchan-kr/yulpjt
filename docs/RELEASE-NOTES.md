## v1.1 — 2026-09-21 (현장 배포 2026-09-23)

### 변경
- **fix: 통신 노이즈 글리치로 수동 진공이 꺼지던 문제** (`ea1d987`)
  - 증상: 수동 진공 ON 상태로 자동 운전 중, 간헐 RS-485/USB 노이즈(재열거)로 진공 명령이 즉시 OFF 래치되던 문제.
  - 수정: `_flag_comm_error` 에서 진공을 바로 끄지 않고 **연속 실패 `comm_fail_latch_count`회(기본 5≈0.5s) 이상**일 때만 OFF 래치. 순간 글리치는 flush 를 건너뛰어 ADAM DO 가 이전 출력을 유지 → 물리 진공 유지, 복구되면 자동 재개. `Config.comm_fail_latch_count` / env `COMM_FAIL_LATCH` 로 조정.
  - 안전정지(EMO/구동허가)는 종전대로 즉시 OFF.
- **docs: 조작 설명서에 기구 외형/도면 추가 + 전장 도면 부록** (`ab0cb44`)

### 현장 설정 (코드 아님, 배포 환경)
- 파이 유저 서비스에 **`Environment=COMM_FAIL_LATCH=100000`** 추가 (2026-09-23).
  - 목적: "진공은 계속 유지" 요구 — 통신 노이즈로는 진공이 사실상 절대 OFF 되지 않게(사용자 OFF·안전정지·SOL OFF 시에만 OFF).

## v1.0 — 2026-08-17 (초기 납품본)

태그 `v1.0` → 커밋 `453ba54`

RPT-1000 초기 납품 버전. 주요 기능·이력.

### HMI / 화면
- PySide6 7" 터치 HMI(1024×600), **라이트 테마 + 전면 한글화**(v0.4).
- 화면: 운전(현재 동작·하중·트렌드·진공) / 조건설정(+레시피 3슬롯) / 시스템상태(모듈 램프·아날로그 페어) / 로그(운전기록·**알람**·이벤트·트렌드) / 도움말(+하드웨어 조정) / 유지보수(관리자, 캘리브레이션).
- 키오스크 자동시작(labwc autostart + systemd user), 부팅 화면, 안전정지 모달(상태확인·**부저정지**·안전복귀).

### 제어 로직
- 상태머신: 자동 반복 가압(하강→가압유지→상승→유지→카운트), 완료 후 **교체 위치(상단)로 이동 정지**.
- **하강/상승 위치센서 미도달 = 정상 처리**(시료 크기 대응, 시간 기반). 과가압은 **하중 상한(LOAD_OVER_LIMIT)** 보호.
- **하강 하중 도달 판정**(옵션): 로드셀 기준값으로 도달 판정.
- 수동: Up/Down(센서 도달 정지), **교체 위치 이동**.
- **진공 = 수동 전용·자동과 완전 분리**. 안전정지 시 액추에이터/진공 강제 OFF, 복귀 후 재입력.
- **부저: 안전 복귀까지 지속** + 부저정지(음소거).

### 하드웨어 통합
- ADAM-4055×2(DIO) + ADAM-4017+(AI) + ADAM-4561(USB-RS485), **Advantech ASCII(DCON)** 드라이버(주소 1/2/3, 9600 8N1).
- 로드셀 CSB-1T(1000kgf) 4–20mA, ±10V 읽기 + 120Ω 환산.
- **USB 재열거 자동 재접속**(by-id 재탐색), 통신오류 앱 무정지·자동복구, `data/app.log` 회전 로깅.
- 입력 반전 IntEnum 채널충돌 수정(MODE_AUTO/VACUUM_OK), AUTO/MANUAL 셀렉터 반전.

### 문서
- **조작 설명서 v1.0**(`docs/manual/반복가압측정기_매뉴얼.pdf`) — 화면 콜아웃·제어함 스위치·레시피·하드웨어 조정. HTML→PDF 빌드(`build_html_pdf.py`).

## 알려진 이슈 / 하드웨어 대책 (진행 예정)

- **USB 재열거 노이즈(근본 원인)**: 자동 운전 중 솔레노이드 스위칭 노이즈가 USB로 전도되어 **CP2103(통신)·터치 컨트롤러**가 재열거. 심하면 **터치 먹통**(화면은 정상, 물리 DIO 버튼은 동작). 소프트(진공 유지·자동재접속)로 완화했으나 근본은 하드웨어.
  - 대책: **UPS**(전원 안정, 계획 중) · **솔레노이드 코일 플라이백 다이오드 + 접점 RC 스너버**(소스 억제) · **터치 USB 케이블 페라이트** · 통신선/동력선 분리.
- **매뉴얼 미기재 항목**: 전원 세부(차단기)·외형/중량 실측, 전면도/공압도/전기도 일부 [그림].

## 원격 업데이트 방법 (요약)

- **인터넷 있을 때**(파이가 GitHub 도달): `cd ~/control-system && git fetch --all --tags && git reset --hard vX.Y && systemctl --user restart control-system.service`
- **오프라인 직결**: `dist/rpt-vX.Y.bundle` + SSH 키로 `dist/site-update.sh` (README-현장업데이트.txt 참고).
