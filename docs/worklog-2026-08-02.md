## 1. 통신 안정성 (USB 재열거 대응)

- **`aec3a4f` 통신오류에 앱이 얼지 않고 자동복구** — scan/`_tick` 예외 방어.
- **`b0d190f` 앱 파일 로깅 추가** — `~/control-system/data/app.log`(RotatingFileHandler).
  유저 journald가 영속화 안 돼 사후 진단 불가였던 문제 해결. 통신오류 진입(엣지 1회)·잡아먹힌 예외 기록.
- **`09d1fac` USB 재열거 시 시리얼 자동 재접속 (멈춤 근본 원인)**
  - 현장 로그·dmesg로 확인: 솔레노이드 스위칭 노이즈로 **CP2103(ADAM-4561) USB 어댑터가 순간 재열거(ttyUSB1→ttyUSB0)** → 열린 fd 사망(SerialException). 기존 방어는 포트를 재오픈 안 해 영구 통신오류로 굳어 멈췄다.
  - `AdamSerialBus.command`: 시리얼 오류 시 `_reopen()`(by-id 재탐색)+retries 재시도 → 다음 스캔에서 자동복구. 실전 재열거(#12)에서 **~1초 끊김 후 자동복구** 검증.
- **`326efa6` / `5db2d40` 버스 트래픽 감축**
  - 시스템상태 페이지를 캐시 전용으로(매 틱 하드웨어 재폴링 제거).
  - 로드셀 스캔당 중복 시리얼 읽기 제거(`read_kgf`/`current_valid`/유지보수 페이지 → 캐시 재사용). 스캔당 시리얼 2건 감소.

## 2. 자동/수동 동작 로직

- **`b0d190f` 수동 위치센서 정지** — 수동 상승은 `CYL_UP_POS` 닿으면 밸브 정지. 수동 하강은 `CYL_DOWN_POS` 닿으면 정지하되, 샘플 크기로 센서 미도달이어도 **에러 없이 계속 가압**(수동은 타임아웃 없음).
- **`9836bbc` 자동 하강 위치센서 미도달 = 정상 진행** — 샘플 때문에 `CYL_DOWN_POS`가 동작 안 할 수 있어 `DOWN_TIMEOUT` 폴트 제거. 이동시간 경과 시 정상적으로 다웰 진입. 상승은 `UP_TIMEOUT` 유지. 과가압은 `LOAD_OVER_LIMIT`가 보호.
- **`8b3459d` 하강 하중 도달 판정(신규)** — 자동 하강 중 로드셀 ≥ 기준값이면 '도달'로 보고 다웰 진입(위치센서 없이). 조건설정에 `하강 하중 도달 사용`(체크박스)+`하강 도달 하중(kgf)`. RuntimeSettings `down_load_detect`/`down_load_threshold_kgf`.

## 3. 진공 (수동 전용·완전 분리)

- **`5eba3c9` 진공을 수동 전용·시스템과 완전 분리** — 진공 명령이 없으면 진공 센서를 감시하지 않음(이상경고 미발생). `vacuum_status`도 미명령 시 항상 OFF. 자동 사이클은 원래도 진공 구동/참조 안 함.

## 4. 입력 반전 버그 (중요)

- **`1885360` 입력 반전의 IntEnum 채널 충돌 제거**
  - `DI1.MODE_AUTO`(ch0)와 `DI2.VACUUM_OK`(ch0)가 IntEnum이라 `==`로 같게 판정 → 반전 집합이 단순 signal 집합이면 `invert_mode_auto=True`를 켠 순간 **VACUUM_OK까지 오반전**(무진공인데 '정상' 표시. 사용자가 '진공 극성 반대'로 관측한 진짜 원인).
  - IO `input_invert`를 `(타입명, 채널)` 키로 저장/판정해 모듈 간 채널 격리.
  - `invert_vacuum_ok=False`(진공 원신호가 정상 극성), `invert_mode_auto=True` 유지.
- **`d1ea526` AUTO/MANUAL 셀렉터 반전** — 셀렉터 결선이 반대라 `config.invert_mode_auto=True`. 수동 모드 실기 확인 완료.

## 하드웨어 이슈 & 조치

### (해결) EMO 눌러도 솔레노이드 안 멈춤 — DO COM에 P24 오배선
- 증상: EMO/라이트커튼 모두 `구동 차단`은 뜨는데(소프트는 두 코일 OFF 명령), EMO에선 실린더가 안 멈춤.
- 밸브 = **TPC DS6340-5DZ-06 = 5/3 클로즈드센터(스프링센터)**. 양 코일 OFF → 중립 → 실린더 포트 차단 → 그 자리 정지가 정상.
- **원인: ADAM-4055 DO(오픈컬렉터 싱크)의 DO COM에 P24(+24V)가 잘못 물려 있었음.** 코일이 그 경로로 계속 통전 → 5/3 밸브가 중립으로 못 감. **P24 제거 → 정상 정지.**
- 교훈: **싱크 출력 COM에는 반드시 0V(N24). +24V 금지.**

### (진행 중) P24 제거 후 재접속(USB 재열거) 증가 — 솔 스위칭 노이즈
- P24 제거로 코일이 이제 **정상적으로 OFF** → 인덕티브 플라이백 스파이크 발생 → CP2103 재열거.
- **릴레이 경유 구동**: Omron **MY2N-D2 DC24**(코일 다이오드 내장 → 코일측 OK) + 소켓 **PYFZ-08-E**.
- **필요 조치 (솔 = DC24V 확인):**
  1. **각 솔레노이드 코일 양단에 플라이백 다이오드 `1N4007`** (캐소드=+24V쪽). ← 최우선, 대부분 이걸로 해결. 양솔이므로 2개.
  2. (선택) 릴레이 NO 접점 양단에 **RC 스너버 0.1µF+100Ω** — 잔여 접점 아크 EMI.
  3. (선택) 응답속도 필요 시 다이오드+제너 또는 TVS(P6KE33A/SMAJ33A).
  4. 가장 깔끔: DS6340이 DIN 43650이면 **서지억제(다이오드 내장) DC 커넥터**로 교체(무납땜).
  5. 부수: USB 케이블 페라이트, 전원/솔 배선과 USB·RS-485 분리, 전원 분리(스타 접지).
- 적용 후 상단바 **재접속 카운터로 전/후 정량 비교** 권장.
