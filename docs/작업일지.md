## 2026-09-23 — v1.1 현장 배포 + 터치 먹통 긴급 대응

- 📦 **v1.1(`ea1d987`) 현장 배포.** (당시 파이가 인터넷 가능해 직접 `git fetch`로 갱신.)
- 🔴→🟡 🔧 **증상: 자동 운전 중 HMI 터치 먹통 + 진공 OFF.** 운영자 보고 "진공 켜기가 안 먹힘". 조사 결과:
  - 물리 DIO 버튼은 동작, **HMI 터치만 먹통**(화면 표시는 정상).
  - `dmesg`에서 **터치 컨트롤러 USB(usb 3-2)가 약 0.5초마다 끊임없이 재열거**(디바이스 번호 계속 증가). `/proc/bus/input/devices`에 터치 장치 없음 → 터치 입력 소실.
  - 원인: **솔레노이드 스위칭 노이즈가 USB로 전도** → CP2103(통신)·터치 컨트롤러 동시 재열거. (통신 노이즈로 진공도 OFF 되던 것과 같은 소스.)
  - **조치: 재부팅으로 USB 재열거 폭주 해소**(재부팅 후 재열거 1회만, 정상).
- 🟡 💻 **진공 유지 설정 적용:** 사용자 요구 "진공은 계속 유지되어야 함" → 유저 서비스에 `Environment=COMM_FAIL_LATCH=100000` 추가. 통신 노이즈로는 진공이 사실상 OFF 되지 않음(사용자 OFF/안전정지/SOL OFF 시에만). sudo 불필요, 재부팅에도 유지.
- 📝 이때까지 근본(하드웨어 노이즈)은 미해결 → UPS·스너버·**페라이트** 필요성 식별. (→ 2026-10-09 페라이트로 해결)
